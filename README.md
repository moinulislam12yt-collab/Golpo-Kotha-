# গল্পঘর — Android App

এটি একটি প্রথম ভার্সনের Android Studio প্রজেক্ট।

ফিচার:
- বাংলা গল্পের Home screen
- Story categories
- Story search
- Story reader dialog
- Demo automatic story writer
- Mobile-friendly design

চালানোর নিয়ম:
1. Android Studio খুলুন।
2. এই project folder (`Golpo_App_Android`) Open করুন।
3. Gradle sync শেষ হতে দিন।
4. Emulator বা Android ফোন connect করুন।
5. Run চাপুন।

নোট:
Automatic Story Writer বর্তমানে demo/local text generator। পরের ধাপে নিরাপদ backend-এর মাধ্যমে AI API যুক্ত করা যাবে।
